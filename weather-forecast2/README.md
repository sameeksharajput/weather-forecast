# Weather Forecast Dashboard

## Run in VS Code
1. Extract the ZIP.
2. Open the `weather-forecast` folder in VS Code.
3. Open a terminal in that folder.
4. Install dependencies:
   `python -m pip install -r requirements.txt`
5. Start the dashboard:
   `python -m streamlit run app.py`
6. Open the **Local URL** printed in the terminal.

The dashboard uses Open-Meteo's free forecast API (internet required). `weather_forecast.py` remains your separate historical-data ML training/evaluation script.
